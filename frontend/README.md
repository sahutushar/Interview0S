# InterviewOS — Frontend

Next.js 16 + React 19 + TypeScript frontend for InterviewOS.

## Getting Started

```bash
cp .env.local.example .env.local
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `NEXT_PUBLIC_API_BASE_URL` in `.env.local` to point at the backend (default: `http://localhost:8000`).

## Tech Stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS v4, Framer Motion
- Lucide React icons
